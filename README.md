# ☕ Starbucks Beverage Analytics Dashboard | Power BI

## 📊 Project Overview

I built an interactive **Starbucks Beverage Analytics Dashboard using Microsoft Power BI** to analyze beverage nutrition, caffeine levels, beverage categories, and global presence.

The main objective of this project was to transform raw beverage data into a **clean, interactive, and business-friendly dashboard** that makes important insights easy to understand and explore.

---

## 🎯 Business Objective

The dashboard was designed to answer questions such as:

- How many beverages are available?
- What is the average sugar, calorie, and caffeine content?
- Which beverage categories have the highest calories?
- Which categories contain the highest caffeine levels?
- How are beverages distributed across categories?
- Which beverages have the highest caffeine content?
- What does the global presence of Starbucks look like?

## 🔄 Data Analysis Process

### 1. Data Import
- Imported the beverage dataset into Power BI.
- Reviewed the structure and available fields.

### 2. Data Cleaning
- Cleaned and transformed the data using **Power Query Editor**.
- Checked data types and handled inconsistencies.
- Prepared the dataset for analysis and visualization.

### 3. Data Modeling
- Organized the dataset for efficient reporting.
- Created the required relationships and analytical fields.

### 4. DAX Analysis
Created measures for key metrics using DAX functions such as:

- `AVERAGE`
- `COUNTROWS`
- `TOPN`
- `CALCULATE`

### 5. Dashboard Development
Built interactive visuals including:

- KPI Cards
- Line/Area Chart
- Bar Chart
- Donut Chart
- Map Visual
- Top 5 Analysis
- Interactive Slicers
- Filters

## 📈 Key Insights

### ☕ Beverage Category Analysis

The dashboard compares beverage categories based on their average calorie and caffeine content, helping identify categories with relatively higher nutritional and caffeine levels.

### ⚡ Caffeine Analysis

The **Average Caffeine by Category** visual helps compare caffeine levels across different beverage categories.

### 🏆 Top 5 Analysis

A dedicated **Top 5 Highest Caffeine Beverages** section highlights the beverages with the highest caffeine values in the dataset.

### 🌎 Global Presence

The map visual provides a geographical view of Starbucks' global presence.

### 🥤 Category Distribution

The donut chart shows how beverages are distributed across different categories.
